# Credits & Third-Party Notices

## Third-party code and assets

**None.** Cursor Bots ships with zero third-party dependencies:

| Area | How it's made | License impact |
|------|---------------|----------------|
| Code | Hand-written vanilla JavaScript (ES modules), HTML and CSS | Covered by this project's MIT `LICENSE` |
| Graphics | Drawn procedurally at runtime on HTML `<canvas>`; icons are original SVGs in `icons/` | Original work |
| Audio | Synthesized live with the Web Audio API (no audio files) | Original work |
| Fonts | The device's built-in system font stack (`system-ui`, etc.); no font files are bundled | Nothing to credit |
| Build tools | None required; `tools/` scripts use only Node.js built-ins | Not distributed |

If you add a library, font, sound or image later, add its name, author, source URL and license here
(and include its license text if the license requires it, e.g. MIT/Apache/OFL/CC-BY).
